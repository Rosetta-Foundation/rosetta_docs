# PRD-0027 research record

Research companion to [PRD-0027: Personal Chronicle](../../PRD-0027-personal-chronicle.md).

The PRD is **Accepted** and stays scoped. This folder tests whether the Path
hypothesis is a useful primitive. It does not widen the PRD, invent a product
category, or authorize a capture prototype.

## Posture

- **Focused in product definition.** PRD-0027 is the ethical and conceptual
  floor. Do not inflate it into a universal theory.
- **Open in research.** Independent recognition is a signal, not proof. Look
  for counterevidence.
- **Precise in language.** Distinguish path from timeline, graph edge, activity
  log, and generated narrative.
- **Humane by design.** Consent, correction, privacy, selective forgetting, and
  non-coercion are constraints, not features to add later.
- **Humble about destination.** Finding a promising trail is not arrival.

> Blaze the path. Then walk it.
