# Path research brief

The question is no longer how to describe Personal Chronicle. The question is:

> **Is the underlying Path hypothesis actually a new and useful primitive, and
> can we demonstrate that it matters?**

This brief operationalizes that question. It does not change
[PRD-0027](../../PRD-0027-personal-chronicle.md).

## Working definition

**Path (candidate primitive):** a first-class, attributable, revisable record
of meaningful movement and relationship across time.

A path can include sequence, attention, context, revisiting, friction,
questions, source material, detours, collaborators, commitments, and later
reinterpretation. It is not a static link between two nodes. It is the lived
and revisable relationship among them over time.

The point is not to record every click or automate biography. The point is to
make selected, meaningful trajectories available for recall, reflection,
transfer, and correction.

## Core hypothesis

> **Meaning is often carried not only by the things a person knows or records,
> but by the path through which those things became connected.**

Type: **I** (interpretive) with an empirical edge (**P** / **H** once
experiments run).  
Confidence: **Working hypothesis**.  
Basis: Rosetta story Ch. 6–10; PRD-0027 contracts; independent reader
recognition ([reader-feedback.md](reader-feedback.md) Feedback 1).  
What would change this: experiments in which curated paths add no advantage
over endpoints, or add advantage only by increasing volume of text.

## Distinctions that must survive a language test

| Term | What it is | What it is not |
| ---- | ---------- | -------------- |
| **State** | What is true or present now | How it became so |
| **Trajectory / path** | How a state became present, including abandoned alternatives | An audit log bolted onto a profile |
| **Timeline** | Ordered events | Meaningful relationship among events |
| **History** | A retrospective account | A first-class, revisable object while the work is live |
| **Graph edge** | A typed link between nodes | Sequence, friction, attention, later reinterpretation |
| **Story** | A narrated telling | Provenance-bearing structure a person can correct without rewriting the past |

A collection of records is not a path. Relationships are part of the meaning.

## Frontier hypotheses

Treat each as a hypothesis, not a conclusion. Confidence is an **upper bound**
until a human or cross-lineage pass lands
([`../../../process/adversarial-review.md`](../../../process/adversarial-review.md)).

| ID | Hypothesis | Type | Confidence | Disconfirming evidence |
| -- | ---------- | ---- | ---------- | ---------------------- |
| H1 | **Path is a missing primitive.** Existing systems store content, entities, links, and events, but poorly represent meaningful, revisable trajectory. | I/P | Working hypothesis | Landscape shows a product whose primary object is revisable trajectory with provenance, agency, and selective forgetting — not merely edges, events, or generated summaries. |
| H2 | **Curation carries intelligence.** Selection and arrangement preserve understanding that raw capture and isolated summaries lose. | P | Working hypothesis | In path-versus-endpoint tests, a longer uncurated dump matches or beats a short curated path on explanation quality and later revision. |
| H3 | **Trajectory improves transfer.** Inspecting a path yields deeper understanding than receiving only the conclusion. | P | Working hypothesis | Recipients of a concise path show no gain in comprehension, time-to-action, or tradeoff explanation versus a conventional summary of similar length. |
| H4 | **Agency is part of accuracy.** Correction, contextualization, deletion, and bounding are necessary for a trustworthy representation. | N + P | Normative floor; empirical part Working hypothesis | People treat an uncorrectable chronicle as more accurate, or cannot predict the effect of correction/forgetting controls. |
| H5 | **The right unit may be a path, not a document.** Notes, conversations, artifacts, people, and moments may be waypoints. | I | Speculative | People consistently prefer documents or events as the unit of meaning, and path-as-object adds overhead without improving re-entry or transfer. |
| H6 | **Personal and collective paths differ.** A personal path is not a smaller org knowledge graph; privacy, ownership, consent, and emotional meaning change the constraints. | I/P | Working hypothesis | The same capture, sharing, and inference rules work equally well for personal and organizational use without added harm or loss of trust. |

## Candidate personal-domain principle

**The Journey Is the Destination** remains a candidate, not a slogan.

Narrow claim: in human meaning-making, the route by which a person learns,
changes, builds, grieves, recovers, or decides can possess lasting value
independent of the endpoint. A final answer may be useful without preserving
the understanding required to trust, teach, revisit, or revise it.

It must not romanticize hardship, justify inefficiency, or deny outcomes. It
must not become a requirement to preserve everything.

Disconfirming evidence: people consistently value only endpoints once given a
choice; or “journey” framing increases capture pressure and regret.

## Complementary pair (narrative, not product scope)

| Collective | Personal |
| ---------- | -------- |
| **A Practice of Paths** — leave enough path that others can continue the work | **The Journey Is the Destination** — preserve enough path that future-self can continue becoming |

Both rest on: the current state of a system is only partially intelligible
without the path that produced it. That civilizational claim stays in research
and story. It is not a new PRD-0027 requirement.
