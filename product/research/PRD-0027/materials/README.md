# Experiment materials

Artifacts for [Experiment 1](../experiments.md) are **experimental
materials**, not product docs and not PRD scope.

They are created collaboratively by the researcher and conversational
research partner, then reviewed for **comparable information** (same
underlying facts and similar length; representation is the variable).

Rosetta agents must not independently generate Artifact A or Artifact B
without preserving that rationale.

## Status

| Item | Status |
| ---- | ------ |
| Artifact A — destination-oriented | Not created |
| Artifact B — path-oriented | Not created |
| Comparable-information review | Not done |
| Assignment log (participant → A/B) | Not started |
| Raw response archive | Not started |

When the artifacts exist, link or attach them here and record:

- the real-world decision they represent
- word/line counts for A and B
- what was judged “the same information”
- any fact that appears in only one artifact, and why
- who reviewed them and when

Do not put raw participant replies in the public docs repo if they identify
people. Store those in the personal research chronicle and link a redacted
summary after analysis.
